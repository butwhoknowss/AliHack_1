        📘 How to read these results
        Anomaly
        How much a month differed from its normal value for that time of year. Removing the seasonal cycle this way stops "summer is hotter than winter" from hiding the long-term change.
        Trend (rate of change)
        The slope of the best straight line through the data, shown per decade (10 years).
        p-value
        The chance of seeing a trend at least this strong if nothing were really changing. Small p (below α, usually 0.05) → the trend is "statistically significant".
        95 % confidence interval
        The range where the true rate of change probably lies. If it does not include 0, the trend is significant.
        Mann-Kendall test & Sen's slope
        A test that only asks "are later values usually higher (or lower) than earlier ones?". It doesn't need a straight line or bell-shaped noise, so it double-checks the t-test. Sen's slope is the median of all pairwise slopes.
        Why can the same variable trend opposite ways?
        One process — for example warming shifting rain belts — can make one region wetter and another drier. Always check several regions.
